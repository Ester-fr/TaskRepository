# Todo List Application

## Overview
A Java Swing-based Todo List application with real-time JSON persistence.
Allows adding, deleting, marking tasks as DONE, searching, and viewing tasks sorted by status.

## Requirements
- Java JDK 17+
- IDE supporting Java (IntelliJ, Eclipse, etc.)

## Running
1. Open the project in your IDE.
2. Run the main class `ToDoUi`.
3. Interact via the GUI to manage tasks.

## Features
- Add, Delete, Mark DONE
- Search tasks by title or description
- Display tasks sorted by status
- Real-time JSON data persistence

## Notes
- Task IDs are sequential (can be improved later)
- No external libraries required
