# Todo List Application - README

## Overview
A simple Java-based Todo List application with GUI for managing tasks.
Supports: Add, Delete, Mark as Done, Search, and View all tasks sorted by status.
All data is persisted in a JSON file.

## Requirements
- Java JDK 17+
- IDE supporting Java (IntelliJ IDEA, Eclipse, or similar)
